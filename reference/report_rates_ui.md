# Create User interface for dv.reportrates module

Create User interface for dv.reportrates module

## Usage

``` r
report_rates_ui(module_id)
```

## Arguments

- module_id:

  `[character(1)]`

  A unique ID string to create a namespace. Must match the ID provided
  to [`report_rates_server()`](report_rates_server.md)

## Value

A shiny UI.
