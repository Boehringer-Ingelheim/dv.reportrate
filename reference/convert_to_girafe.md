Internal helper function to convert the ggplot object into an
interactive girafe object. Applies all interactive settings: tooltip
behavior, hover effects, selection styling, and toolbar configuration,
except of zoom options. The latter is addressed separately via a feature
based on limiting the min/max values of the plot's axis

## Usage

``` r
convert_to_girafe(ggplot_obj, selected_levels)
```

## Arguments

- ggplot_obj:

  `[ggplot2::ggplot]`

  The ggplot object generated by create_plot().

- selected_levels:

  `[character(0+)]`

  Character vector containing the currently selected grouping levels
  that should be displayed in the plot.

## Value

A `[ggiraph::girafe]` object. An interactive ggplot-based visualization
showing calculated rates over time based on the selected grouping
variable and levels, metric, and time unit.
